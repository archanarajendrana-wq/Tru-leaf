Truleaf homepage — run locally
------------------------------
1. Open a terminal in this folder.
2. Run:  python3 -m http.server 8000
3. Open: http://localhost:8000  in your browser.
4. Edit index.html / tokens.css and refresh to see changes.

Files:
  index.html    — the page (links tokens.css + webimg/)
  tokens.css    — design tokens (indigo-primary palette, type, spacing)
  webimg/       — hero + section images
